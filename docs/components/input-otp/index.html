验证码输入

分格的一次性验证码输入，支持粘贴整串与自动跳格。

安装

用 CLI 命令添加此组件族，或按手动步骤复制源码。

已支持深色模式，颜色取自语义设计变量。

CLI 会把组件源码（及其依赖的内部文件）复制到你的项目中，并安装所需的 npm 包。

$ npx shadcn@latest add https://wangxiaobo97.github.io/qiguanui-registry/r/input-otp.json

使用共享 UI 包或自定义导入别名？请先 配置安装路径，再执行命令。

装完还需引入一次设计变量

CLI 会把 styles/qiguan-tokens.css 放进项目，但不会自动引用它。在你的全局样式里加一行即可（相对路径按实际位置调整）：

css
@import "tailwindcss"; @import "../styles/qiguan-tokens.css";

这一行提供全部语义色、字号与自定义工具类。漏掉不会报错，但视觉失效。

分格验证码

每位一个格子，输入后自动跳到下一格，退格回到上一格。粘贴整串会被自动拆开填入。

usage
<InputOtp aria-label="验证码" length={6} />

分组

groupEvery 每 N 位插一个间隔，6 位验证码通常设 3，读起来是「3+3」而不是一串。 只影响视觉，值本身不带分隔符。

usage
{/* groupEvery 每 N 位插入一段间隔，短信验证码常用 3 */} <InputOtp aria-label="验证码" length={6} groupEvery={3} />

InputOtp

属性类型默认值说明
lengthnumber6格子数量。
aria-label*string—没有可见标签，必须给名称。
value / defaultValuestring—受控与非受控二选一。
onChange(value: string) => void—每次变化都触发。
onComplete(value: string) => void—填满时触发，适合在这里发起校验。
groupEverynumber—每 N 位插入一个间隔。
isInvalidboolean—校验失败态。
isDisabledboolean—禁用态。
